# TechSummary
## Script for summary information about current Linux machine

Summary info contains:
- date and time in ISO format
- name of current machine
- used Linux distro 
- MAC addresses
- current IP address
- list of installed packages

Usage:
- techsummary -s <filename.json> - saves summary as .json file
-  techsummary -s - prints summary to console
- techsummary -c <file1> <file2> - compares 2 summary files
- techsummary -h - prints help
